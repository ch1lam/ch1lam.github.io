# OG image font

`LXGWWenKaiLite-Regular.ttf` is the unmodified regular font from
[LXGW WenKai Lite](https://github.com/lxgw/LxgwWenKai-Lite), downloaded 2026-09-29
from `fonts/TTF/LXGWWenKaiLite-Regular.ttf`. The SIL Open Font License is included
in `OFL.txt`.

This font is only read during static OG image generation. It is not shipped to
visitors. It keeps Chinese titles readable without Google Fonts requests at build
time. The website continues to use LXGW WenKai Screen via the existing CDN.
